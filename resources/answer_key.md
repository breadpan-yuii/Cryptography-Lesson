# Answer Key and Explanations

## Caesar Cipher
1. "CRYPTOGRAPHY IS FUN" with key 7 becomes "JZAAVWZLJYVZ PZ M" (one possible result depending on spaces).
2. "KZJYJH" with shift 5 decrypts to "FUNDS?" if treated as letters only.
3. It is easy to break because there are only 25 possible shifts.

## Vigenère Cipher
1. The Vigenère process uses the keyword to determine repeated shifts.
2. It is stronger because the shift changes with each letter.
3. The Kasiski examination looks for repeated sequences to estimate key length.

## Playfair Cipher
1. The matrix is built by placing the keyword letters first, then the rest of the alphabet.
2. Encryption depends on the positions of the pair in the matrix.
3. Same-row moves right; same-column moves down.

## Rail Fence Cipher
1. The rail fence arrangement depends on the zigzag pattern across the selected rails.
2. Frequency is preserved because the letters are only rearranged.
3. Caesar replaces letters; rail fence reorders them.
