# Challenge Problems

## Caesar Cipher
1. Encrypt the phrase "CRYPTOGRAPHY IS FUN" with key 7.
2. Decrypt the ciphertext "KZJYJH" using a Caesar shift of 5.
3. Explain why a Caesar cipher is easy to break.

## Vigenère Cipher
1. Encrypt the phrase "SECRETMESSAGE" with keyword "KEY".
2. Why does the Vigenère cipher provide better security than Caesar?
3. Describe the Kasiski examination.

## Playfair Cipher
1. Create a Playfair matrix using the keyword "MATH".
2. Encrypt the digraph "HI".
3. Explain the difference between same-row and same-column rules.

## Rail Fence Cipher
1. Encrypt the message "EDUCATION" using 3 rails.
2. Explain why transposition ciphers preserve letter frequencies.
3. Compare rail fence with Caesar.
